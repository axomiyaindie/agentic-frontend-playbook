# Curated Developer Toolkit

A curated collection of websites, open-source projects, GitHub repositories, libraries, and developer tools for building modern frontend applications, interactive 3D websites, animations, and AI-powered development workflows.

The goal is simple: help developers discover useful tools, understand what they do, and start using them without spending hours searching.

## Resource Entry Format

Every resource should follow a consistent format:

### Tool or Project Name

- **Website:** [Official website](https://example.com)
- **GitHub:** [Repository](https://github.com/example/project)
- **Type:** Open source / Free / Commercial
- **Purpose:** A short explanation of what the tool does.
- **Use cases:** What developers can build or accomplish with it.
- **Getting started:** Installation command, documentation link, or quick-start instructions.

Only include verified official links. Do not invent repository URLs, installation commands, pricing, or license information.

## Selection Guidelines

Prioritize resources that:

- Solve real development problems.
- Are useful for modern frontend and 3D web development.
- Have clear documentation.
- Are actively maintained, where possible.
- Offer practical value to developers and AI coding agents.
- Can be accessed or installed directly.

Avoid duplicate entries, abandoned projects without a clear reason to retain them, and low-quality link collections.

## Contributing Resources

Contributors are welcome to suggest useful websites, GitHub repositories, and developer tools.

Every submission should include the official link and a concise explanation of what the resource does and why it is useful.

The collection should prioritize quality, practical value, and discoverability over quantity.
