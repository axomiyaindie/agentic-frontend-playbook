# Design Resources

A collection of design platforms, icon libraries, typography resources, color tools, and visual inspiration for modern digital products.

## Design and Prototyping

### Figma
- **Website:** https://www.figma.com/
- **Purpose:** Collaborative interface design, prototyping, and design-system management.
- **Use cases:** Product UI, wireframes, prototypes, and component libraries.
- **Getting started:** https://help.figma.com/

### Penpot
- **Website:** https://penpot.app/
- **GitHub:** https://github.com/penpot/penpot
- **Purpose:** Open-source design and prototyping platform.
- **Use cases:** Interface design, collaborative prototyping, and design systems.
- **Getting started:** https://help.penpot.app/

### Excalidraw
- **Website:** https://excalidraw.com/
- **GitHub:** https://github.com/excalidraw/excalidraw
- **Purpose:** Collaborative sketching and diagramming tool.
- **Use cases:** Architecture diagrams, user flows, wireframes, and technical explanations.
- **Getting started:** Open the web application or explore the repository for integration options.

## Icons

### Lucide
- **Website:** https://lucide.dev/
- **GitHub:** https://github.com/lucide-icons/lucide
- **Purpose:** Consistent open-source SVG icon library.
- **Use cases:** Navigation, buttons, dashboards, and interface components.
- **Getting started:** https://lucide.dev/guide/

### Heroicons
- **Website:** https://heroicons.com/
- **GitHub:** https://github.com/tailwindlabs/heroicons
- **Purpose:** SVG icon collection designed for modern interfaces.
- **Use cases:** Web application and product UI.
- **Getting started:** https://github.com/tailwindlabs/heroicons

### Phosphor Icons
- **Website:** https://phosphoricons.com/
- **GitHub:** https://github.com/phosphor-icons
- **Purpose:** Flexible icon family with multiple visual weights.
- **Use cases:** Product interfaces, dashboards, and design systems.
- **Getting started:** https://github.com/phosphor-icons

## Typography

### Google Fonts
- **Website:** https://fonts.google.com/
- **GitHub:** https://github.com/google/fonts
- **Purpose:** Discoverable collection of web fonts.
- **Use cases:** Interface typography, multilingual websites, and branding.
- **Getting started:** Choose a font family and follow its official embedding instructions.

### Fontshare
- **Website:** https://www.fontshare.com/
- **Purpose:** Font discovery platform.
- **Use cases:** Brand identity, editorial design, and interface typography.
- **Getting started:** Review the license and usage terms for each typeface.

## Colors and Design Systems

### Coolors
- **Website:** https://coolors.co/
- **Purpose:** Color palette generation and exploration.
- **Use cases:** Brand colors, UI palettes, and theme development.
- **Getting started:** Generate a palette and check contrast before using it.

### Radix Colors
- **Website:** https://www.radix-ui.com/colors
- **GitHub:** https://github.com/radix-ui/colors
- **Purpose:** Structured color scales for interface design.
- **Use cases:** Light and dark themes, semantic tokens, and component states.
- **Getting started:** https://www.radix-ui.com/colors/docs/overview/usage

### Material Design
- **Website:** https://m3.material.io/
- **Purpose:** Design system and guidance for digital interfaces.
- **Use cases:** Components, interaction patterns, accessibility, and visual consistency.
- **Getting started:** Explore the foundations and component documentation.

### Behance

## Responsible Use

Respect copyright, font licenses, icon licenses, and attribution requirements. Use inspiration to develop original work rather than copying another designer's implementation. Verify usage rights before including assets in a commercial product.
