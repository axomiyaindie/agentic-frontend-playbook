# Frontend Development Tools

A curated collection of frameworks, libraries, component systems, styling tools, and testing utilities for modern frontend development.

## Frameworks and Build Tools

### React
- **Website:** https://react.dev/
- **GitHub:** https://github.com/facebook/react
- **Purpose:** A JavaScript library for building component-based user interfaces.
- **Use cases:** Interactive applications, reusable UI components, dashboards, and complex frontend experiences.
- **Getting started:** https://react.dev/learn

### Next.js
- **Website:** https://nextjs.org/
- **GitHub:** https://github.com/vercel/next.js
- **Purpose:** A React framework for building full-stack web applications.
- **Use cases:** SaaS products, websites, dashboards, server-rendered applications, and content platforms.
- **Getting started:** https://nextjs.org/docs/app/getting-started

### Vite
- **Website:** https://vite.dev/
- **GitHub:** https://github.com/vitejs/vite
- **Purpose:** A modern frontend development server and build tool.
- **Use cases:** React, Vue, Svelte, and other frontend projects.
- **Getting started:** `npm create vite@latest`

### Astro
- **Website:** https://astro.build/
- **GitHub:** https://github.com/withastro/astro
- **Purpose:** A web framework focused on content-driven websites and reduced client-side JavaScript.
- **Use cases:** Documentation, blogs, portfolios, marketing websites, and content platforms.
- **Getting started:** https://docs.astro.build/en/getting-started/

### TypeScript
- **Website:** https://www.typescriptlang.org/
- **GitHub:** https://github.com/microsoft/TypeScript
- **Purpose:** Adds static type checking to JavaScript.
- **Use cases:** Safer application development, maintainable codebases, and better editor support.
- **Getting started:** https://www.typescriptlang.org/docs/

## Styling and UI Libraries

### Tailwind CSS
- **Website:** https://tailwindcss.com/
- **GitHub:** https://github.com/tailwindlabs/tailwindcss
- **Purpose:** Utility-first CSS framework.
- **Use cases:** Responsive layouts, design systems, and rapid UI development.
- **Getting started:** https://tailwindcss.com/docs/installation

### shadcn/ui
- **Website:** https://ui.shadcn.com/
- **GitHub:** https://github.com/shadcn-ui/ui
- **Purpose:** Customizable React components that developers add directly to their projects.
- **Use cases:** SaaS dashboards, admin panels, forms, and product interfaces.
- **Getting started:** https://ui.shadcn.com/docs/installation

### Radix UI
- **Website:** https://www.radix-ui.com/primitives
- **GitHub:** https://github.com/radix-ui/primitives
- **Purpose:** Accessible, unstyled UI primitives.
- **Use cases:** Dialogs, dropdowns, menus, popovers, and accessible interactive components.
- **Getting started:** https://www.radix-ui.com/primitives/docs/overview/introduction

### React Aria
- **Website:** https://react-spectrum.adobe.com/react-aria/
- **GitHub:** https://github.com/adobe/react-spectrum
- **Purpose:** Accessible interaction patterns and component behavior for React.
- **Use cases:** Custom design systems and accessibility-focused interfaces.
- **Getting started:** https://react-spectrum.adobe.com/react-aria/getting-started.html

### Storybook
- **Website:** https://storybook.js.org/
- **GitHub:** https://github.com/storybookjs/storybook
- **Purpose:** Develop and document UI components independently from the main application.
- **Use cases:** Component libraries, visual review, and design-system development.
- **Getting started:** https://storybook.js.org/docs/get-started

## State Management and Data

### Zustand
- **Website:** https://zustand.docs.pmnd.rs/
- **GitHub:** https://github.com/pmndrs/zustand
- **Purpose:** Lightweight state management for React.
- **Use cases:** Application state, UI state, and shared component data.
- **Getting started:** `npm install zustand`

### TanStack Query
- **Website:** https://tanstack.com/query/latest
- **GitHub:** https://github.com/TanStack/query
- **Purpose:** Server-state management, caching, and asynchronous data synchronization.
- **Use cases:** API requests, server data, caching, and mutations.
- **Getting started:** https://tanstack.com/query/latest/docs/framework/react/overview

### React Hook Form
- **Website:** https://react-hook-form.com/
- **GitHub:** https://github.com/react-hook-form/react-hook-form
- **Purpose:** Form state management and validation integration for React.
- **Use cases:** Registration, checkout, onboarding, and complex forms.
- **Getting started:** https://react-hook-form.com/get-started

### Zod
- **Website:** https://zod.dev/
- **GitHub:** https://github.com/colinhacks/zod
- **Purpose:** TypeScript-first runtime schema validation.
- **Use cases:** Validating API responses, forms, configuration, and application data.
- **Getting started:** `npm install zod`

## Testing and Quality

### Vitest
- **Website:** https://vitest.dev/
- **GitHub:** https://github.com/vitest-dev/vitest
- **Purpose:** JavaScript and TypeScript testing framework.
- **Use cases:** Unit tests and component tests.
- **Getting started:** https://vitest.dev/guide/

### Playwright
- **Website:** https://playwright.dev/
- **GitHub:** https://github.com/microsoft/playwright
- **Purpose:** Browser automation and end-to-end testing.
- **Use cases:** Testing application workflows across browsers.
- **Getting started:** `npm init playwright@latest`

### Testing Library
- **Website:** https://testing-library.com/
- **GitHub:** https://github.com/testing-library
- **Purpose:** Testing user-facing behavior in UI components.
- **Use cases:** React component testing and accessible interaction tests.
- **Getting started:** https://testing-library.com/docs/

## Adoption Notes

Choose tools based on actual project requirements. Consider framework compatibility, bundle size, accessibility, maintenance activity, and license terms before adding dependencies.
